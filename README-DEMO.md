# Gemini Frontend Clone — Demo Mode

The demo branch keeps the existing Gemini-style chat interface but routes its API calls to a browser-local simulator. It can be deployed as a static Vite application and does not need the backend repository or external infrastructure.

## Run locally

    npm install
    npm run dev

Build and preview:

    npm run build
    npm run preview

## Included workflows

- OTP sign-in, account creation, and password recovery
- Seeded chat history and searchable room list
- Create a new conversation and reload existing conversations
- Submit messages with a simulated thinking delay and deterministic assistant replies
- Basic five-message daily limit and simulated Pro upgrade
- Account profile, password change, dark/light theme, and reset demo action

All demo data is stored in this browser's localStorage. Use Reset demo in the workspace header to clear the synthetic state and session.

## Isolation

The demo branch enables the browser simulator directly in the frontend API helper. It does not send requests to VITE_API_BASE_URL and does not call the production backend. Assistant responses are deterministic templates; they are not generated by Gemini or OpenAI. Pro upgrade only changes local demo state and does not open Stripe.

This branch is for recruiter demonstrations and is not a production authentication or AI service.
